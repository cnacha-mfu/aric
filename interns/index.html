01 / 04

AI & Software

สร้าง AI และซอฟต์แวร์ที่มีคนรอใช้จริง

สมัครสาย AI & Software

สิ่งที่คุณจะทำ

  • ร่วมทีมสร้าง MVP จากโจทย์จริงของโรงพยาบาล ชุมชน และภาคอุตสาหกรรม
  • พัฒนาส่วน AI เช่น ระบบที่เข้าใจภาษาไทยและภาษาถิ่น หรือ "สมอง" ของหุ่นยนต์ดูแลผู้สูงอายุ
  • เตรียมและจัดการข้อมูล โดยใช้ข้อมูลอย่างถูกต้องตามหลักความเป็นส่วนตัว
  • ทำเว็บ แอป และแดชบอร์ดที่พยาบาล ผู้ดูแล หรือลูกค้าใช้ได้จริง

เรามองหา

  • ทุกสาขา ที่เขียนโปรแกรมได้และมีผลงานให้ดูสักชิ้น
  • ยินดีเป็นพิเศษถ้าเคยทำ ML, NLP, เว็บหรือแอป หรือใช้ Python / JavaScript ได้คล่อง

สิ่งที่คุณจะได้

  • โจทย์จริงและผู้ใช้จริง
  • พี่เลี้ยงจากภาคอุตสาหกรรมและสำนักวิชาด้านสุขภาพของ มฟล.
  • ใช้เครื่อง NVIDIA DGX และ AI coding agent ระหว่างรอบ
  • ผลงานใส่ portfolio และหนังสือรับรองการทำงาน

02 / 04

หุ่นยนต์และระบบ

ทำให้หุ่นยนต์ดูแลมองเห็น เคลื่อนที่ และทำงานข้างผู้ป่วยได้อย่างปลอดภัย

สมัครสาย หุ่นยนต์และระบบ

สิ่งที่คุณจะทำ

  • เขียนซอฟต์แวร์หุ่นยนต์ (เช่น ROS 2) เชื่อม AI เข้ากับการเคลื่อนที่และการหยิบจับ บนแพลตฟอร์มเป้าหมาย เช่น AgiBot X2 Ultra และ D1 Edu
  • พัฒนาระบบมองเห็น เช่น ตรวจจับการล้มหรือท่าทางของผู้สูงอายุ
  • ต่อเซนเซอร์และอุปกรณ์ IoT เข้ากับระบบดูแล
  • ร่วมกับเจ้าหน้าที่ ADT ดูแลเครื่อง NVIDIA DGX ที่ทุกทีมใช้ร่วมกัน

เรามองหา

  • ทุกสาขา ที่ชอบลงมือกับหุ่นยนต์ ฮาร์ดแวร์ หรือระบบ Linux
  • ยินดีเป็นพิเศษถ้าเคยทำ ROS, OpenCV, Arduino/ESP32, หุ่นยนต์แข่งขัน หรือดูแลเซิร์ฟเวอร์

สิ่งที่คุณจะได้

  • โจทย์จริงจากงานดูแลผู้ป่วยและผู้สูงอายุ
  • พี่เลี้ยงจากภาคอุตสาหกรรมและสำนักวิชาด้านสุขภาพของ มฟล.
  • ใช้เครื่อง NVIDIA DGX และ AI coding agent ระหว่างรอบ
  • ผลงานใส่ portfolio และหนังสือรับรองการทำงาน

03 / 04

ออกแบบและสื่อสาร

เล่าเรื่องของ ARIC และออกแบบหน้าจอที่ผู้สูงอายุใช้ได้ง่าย

สมัครสาย ออกแบบและสื่อสาร

สิ่งที่คุณจะทำ

  • ออกแบบกราฟิกบูธ โปสเตอร์ประกาศรับสมัครแฮกกาธอน และภาพสำหรับโซเชียลมีเดีย
  • ออกแบบ UX/UI ของแอปที่ทีมสร้าง ให้ผู้สูงอายุและพยาบาลใช้ได้จริง
  • เขียนคอนเทนต์ภาษาไทยและอังกฤษ ถ่ายและตัดต่อคลิปเดโมของทีม
  • ช่วยทีมจัดหน้าสไลด์สำหรับวัน Launch

เรามองหา

  • ทุกสาขา ดูจากผลงานเป็นหลัก
  • ยินดีเป็นพิเศษถ้าใช้ Figma, Illustrator, Canva หรือโปรแกรมตัดต่อได้ และจัดตัวอักษรภาษาไทยได้สวย

สิ่งที่คุณจะได้

  • ผลงานที่ได้ใช้จริงในงานแสดงระดับประเทศและในแอปที่มีผู้ใช้จริง
  • ทำงานใกล้ชิดกับทีมที่สร้าง AI และหุ่นยนต์
  • ผลงานใส่ portfolio และหนังสือรับรองการทำงาน

04 / 04

กิจกรรมและธุรกิจ

อยู่หน้างานตั้งแต่แฮกกาธอนจนถึงบูธระดับประเทศ และช่วยพาผลงานไปถึงลูกค้า

สมัครสาย กิจกรรมและธุรกิจ

สิ่งที่คุณจะทำ

  • ช่วยจัดแฮกกาธอน Spark ตั้งแต่รับสมัคร จับคู่ทีม จนถึงคุมเวลาในวันงาน
  • ช่วยเตรียมและดูแลบูธในงานระดับประเทศ เช่น SITE, Techsauce Global Summit และ DigiTech ASEAN Thailand
  • ดูแลชุมชนนักศึกษาและผู้สนใจ ส่งข่าวสารและตอบคำถาม
  • ช่วยงานความร่วมมือและการขาย เช่น เก็บรายชื่อผู้สนใจ เตรียมข้อมูลก่อนพบโรงพยาบาลหรือบริษัท

เรามองหา

  • ทุกสาขา ที่ชอบพบคน เป็นระเบียบ และตรงเวลา
  • ยินดีเป็นพิเศษถ้าเคยจัดกิจกรรมหรือทำงานชมรม สื่อสารภาษาอังกฤษได้ หรือสนใจธุรกิจและสตาร์ทอัพ

สิ่งที่คุณจะได้

  • ประสบการณ์ในงานเทคโนโลยีระดับประเทศ ได้พบผู้ประกอบการ นักลงทุน และหน่วยงานรัฐ
  • ได้เห็นโจทย์จริงจากโรงพยาบาลและชุมชน และวิธีที่ไอเดียกลายเป็นธุรกิจ
  • หนังสือรับรองการทำงาน
